# JARVIS Cloud

A personal AI assistant — mobile-first, cloud-deployed, fully owned by MAK.

## Status
🚧 In development — v1.0 building

## Architecture
- Backend: Python 3.11 + Flask, deployable to Railway
- Frontend: Mobile-first PWA (works on iPhone, Android, desktop browsers)
- Voice: Local Kokoro TTS daemon + OpenAI Whisper STT
- AI: Claude 3-layer routing (Local / Haiku / Sonnet)
- Integrations: Google Calendar, Tasks, Gmail, OpenWeatherMap
